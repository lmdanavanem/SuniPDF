# Security

If you find an exploitable crash, password-protection bypass, incomplete redaction, unsafe update or data leak,
**do not open a public issue**. Contact the maintainer through the address on
[@lmdanavanem's GitHub profile](https://github.com/lmdanavanem), or use GitHub's “Report a vulnerability” feature if enabled.

You will receive an acknowledgement within seven days. Fixes are published in a new release and described in [the changelog](CHANGELOG.md).

The supported scope is versions published on GitHub Releases. PDF processing is local; optional update checks contact GitHub without sending documents.
Downloads must come from the official release, match the application architecture and pass SHA256 validation before installation.
PDFium is loaded dynamically, without JavaScript or XFA execution.
