# Sécurité / Security

*English version below.*

SuniPDF traite des fichiers PDF, un format complexe. Si vous découvrez une vulnérabilité (fichier
provoquant un plantage exploitable, contournement d'une protection par mot de passe, caviardage incomplet,
fuite de données hors de la machine), merci de **ne pas ouvrir d'issue publique** : écrivez à
l'adresse indiquée sur le profil GitHub du mainteneur ([@lmdanavanem](https://github.com/lmdanavanem))
ou utilisez la fonction « Report a vulnerability » de GitHub si elle est activée sur le dépôt.

Vous recevrez un accusé de réception sous 7 jours. Les correctifs sont publiés dans une nouvelle version
et décrits dans `CHANGELOG.md`.

Périmètre : versions publiées sur la page Releases. SuniPDF fonctionne hors ligne et n'envoie aucune
donnée ; le moteur de rendu est PDFium (chargé dynamiquement, sans JavaScript ni XFA).

---

SuniPDF processes PDF files, a complex format. If you find a vulnerability (file causing an exploitable
crash, password-protection bypass, incomplete redaction, data leaving the machine), please **do not open a
public issue**: contact the maintainer through the address on their GitHub profile
([@lmdanavanem](https://github.com/lmdanavanem)) or use GitHub's "Report a vulnerability" feature if it is
enabled on the repository.

You will get an acknowledgement within 7 days. Fixes are published in a new release and described in
`CHANGELOG.md`.

Scope: versions published on the Releases page. SuniPDF works offline and sends no data; the rendering
engine is PDFium (loaded dynamically, without JavaScript or XFA).
