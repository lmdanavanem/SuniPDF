# Code de conduite

[English](CODE_OF_CONDUCT.md)

Ce projet adopte le [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/),
version 2.1. En participant (issues, pull requests, discussions), vous vous engagez à un comportement
respectueux et constructif. Les signalements se font auprès du mainteneur
([@lmdanavanem](https://github.com/lmdanavanem)).
