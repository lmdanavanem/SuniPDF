# SuniPDF 0.41.0 — comptage sur plans et tableau des annotations

Lot source ; qualification de release en cours. La version stable reste [0.40.0](https://github.com/lmdanavanem/SuniPDF/releases/tag/v0.40.0) jusqu’à qualification et publication.

- Comptage par clic sur les plans : repères persistants, groupes, changement de groupe, déplacement/suppression et Annuler/Rétablir.
- Tableau des annotations de toutes les pages : recherche, filtres, tri, navigation, statuts métier, disciplines et champs texte personnalisés.
- Instantanés CSV/JSON avec totaux reliés aux identités réelles, cellules protégées, inconnus explicites et refus des modifications périmées.
- Pillow 13.0.0 réservé aux tests, empreintes des roues Windows et migrations depuis les paquets publiés 0.40.0.
