# Internationalisation

Documentation is maintained in English. The application interface and local OCR continue to support English and French.

## Rules

- Languages: `en-US` (default) and `fr-FR`. Selector under Settings > Language; hot switching;
  preference persisted in `%APPDATA%\SuniPDF\settings.json`.
- **No hard-coded interface string** in `apps/`: everything goes through `sunipdf_i18n::tr(lang, "key")`
  or `tr_args(lang, "key", &[("param", value)])`. Documented exceptions: native language names
  (`Language::native_name`), symbols/icons (◀ ▶ 📂), file names, numbers.
- Source of truth: `assets/i18n/fr-FR.json` and `assets/i18n/en-US.json`, embedded at compile time
  (`include_str!`). Every new key is added **to both** files in the same commit.
- PDF contents are never translated.
- The CLI (`sunipdf-cli`) is an automation tool: messages in English, JSON output, stable error
  codes (`EngineError::code()`). Decision D009.

## Key namespaces

| Prefix | Usage |
|---|---|
| `app.*` | window title |
| `menu.*` | menus and submenus |
| `shortcut.*` | displayed shortcuts (translatable: "Origine" / "Home") |
| `toolbar.*` | toolbar buttons and tooltips |
| `hub.*` | "All tools" hub: `hub.<tool>.name` / `.desc` for the 15 available workspaces declared in `workspace.rs`, including Measurements, OCR, form creation and certificates; `hub.leave`, `hub.back` |
| `status.*` | status bar |
| `bar.*`, `object.kind.*` | object bar (stroke, fill, opacity, angle, group) and object types |
| `objects.*` | Objects panel |
| `text.*` | text typed on the page (`text.inline.*`) and font picker (`text.font.*`) |
| `pagesetup.*` | Crop pages / Resize pages / Insert a blank page dialogs (A3–Legal formats not translated) |
| `signature.*` | **Visual** signature: Sign / Add Initials dialog, pad, import, library, placement and date; `signature.date_format` = `{d}/{m}/{y}` per language, never a strftime pattern |
| `certificate.*` | Existing certificate signing and verification: credentials, integrity, chain/revocation status, timestamp results and explicit network consent |
| `measure.*`, `register.*`, `rich.*` | On-page measurements, saved scales and records, annotation register and rich annotation dialogs |
| `ocr.*`, `office.*`, `form_builder.*`, `recovery.*` | Local OCR, Office conversion, field creation and document recovery |
| `security.*`, `protect.*`, `unprotect.*`, `sanitize.*` | Protection, redaction, metadata cleanup and sanitization controls |
| `clipboard.*` | marker written to the system clipboard when copying objects |
| `forms.*`, `menu.forms.*`, `dialog.flatten.*`, `status.form_*`, `error.form_*`, `a11y.forms.*` | AcroForm forms: banner, field panel (`forms.panel.*`, `forms.kind.<id>` per `FieldKind::id`), XFA / script banners, Flatten dialog, JSON export/import, accessible names of field rectangles, of the editor and of options |
| `empty.*` | empty state |
| `error.*` | error messages (one per `EngineError` variant + UI errors) |
| `comments.*`, `dialog.free_text.*`, `dialog.link.*`, `dialog.url.*`, `dialog.reply.*`, `dialog.comment.*`, `status.annot_*`, `status.link_*`, `bar.annot_*` | advanced annotations: Comments panel as threads (author, statuses `comments.status.<id>` per `ReviewStatus::id`, types `comments.kind.<id>`), text box / link / external address confirmation / reply / comment dialogs, floating bar |
| `dialog.*` | dialogs |
| `about.*` | About |
| `updates.*` | Update checks, downloads, installation confirmation and errors |
| `a11y.*` | texts for screen readers (AccessKit) |

The table groups current namespaces; the two catalogs are the complete key inventory.
Add namespaces when their interface is implemented, rather than relying on a list of reserved future keys.

## Automatic checks

- `crates/sunipdf-i18n`: parity of key sets, no empty value, same `{…}` parameters in both
  languages, unknown key returned as is (never a panic).
- `apps/sunipdf-desktop`: every literal key used in `app.rs`/`main.rs`/`shell.rs`/`workspace.rs` exists in both
  catalogues; every `EngineError` variant has a key.
- `scripts/check-i18n.ps1`: same parity check outside Cargo (CI).

## Adding a key

1. Add `"prefix.name": "…"` to `fr-FR.json` **and** `en-US.json`.
2. Use `tr(lang, "prefix.name")` in the code.
3. `cargo test -p sunipdf-i18n -p sunipdf-desktop`.
