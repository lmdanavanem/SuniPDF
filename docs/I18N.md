# Internationalisation

## Règles

- Langues : `fr-FR` (défaut) et `en-US`. Sélecteur dans Paramètres › Langue ; changement à chaud ;
  préférence persistée dans `%APPDATA%\SuniPDF\settings.json`.
- **Aucune chaîne d'interface en dur** dans `apps/` : tout passe par `sunipdf_i18n::tr(lang, "clé")`
  ou `tr_args(lang, "clé", &[("param", valeur)])`. Exceptions documentées : noms natifs des langues
  (`Language::native_name`), symboles/icônes (◀ ▶ 📂), noms de fichiers, nombres.
- Source de vérité : `assets/i18n/fr-FR.json` et `assets/i18n/en-US.json`, embarqués à la compilation
  (`include_str!`). Toute nouvelle clé est ajoutée **aux deux** fichiers dans le même commit.
- Les contenus des PDF ne sont jamais traduits.
- La CLI (`sunipdf-cli`) est un outil d'automatisation : messages en anglais, sortie JSON, codes d'erreur
  stables (`EngineError::code()`). Décision D009.

## Espaces de noms des clés

| Préfixe | Usage |
|---|---|
| `app.*` | titre de fenêtre |
| `menu.*` | menus et sous-menus |
| `shortcut.*` | raccourcis affichés (traduisibles : « Origine » / « Home ») |
| `toolbar.*` | boutons et infobulles de la barre d'outils |
| `hub.*` | hub « Tous les outils » : `hub.<outil>.name` / `.desc` pour les 14 outils par tâche (les 5 outils absents ont déjà leurs clés, jamais affichées tant que leur fonction n'existe pas), `hub.leave`, `hub.back` |
| `status.*` | barre d'état |
| `bar.*`, `object.kind.*` | barre d'objet (trait, remplissage, opacité, angle, groupe) et types d'objets |
| `objects.*` | panneau Objets |
| `text.*` | texte saisi sur la page (`text.inline.*`) et sélecteur de polices (`text.font.*`) |
| `pagesetup.*` | dialogues Recadrer / Redimensionner / Page vierge (formats A3–Legal non traduits) |
| `signature.*` | signature **visuelle** (boîte Signer / Parapher, pavé, import, bibliothèque, placement, date ; `signature.date_format` = `{d}/{m}/{y}` par langue, jamais un motif strftime) ; la future signature numérique prendra `certificate.*` |
| `clipboard.*` | repère écrit dans le presse-papiers système à la copie d'objets |
| `forms.*`, `menu.forms.*`, `dialog.flatten.*`, `status.form_*`, `error.form_*`, `a11y.forms.*` | formulaires AcroForm : bandeau, panneau des champs (`forms.panel.*`, `forms.kind.<id>` par `FieldKind::id`), bandeaux XFA / scripts, boîte Aplatir, export/import JSON, noms accessibles des rectangles de champs, de l'éditeur et des options |
| `empty.*` | état vide |
| `error.*` | messages d'erreur (un par variante d'`EngineError` + erreurs UI) |
| `dialog.*` | boîtes de dialogue |
| `about.*` | À propos |
| `a11y.*` | textes pour lecteurs d'écran (AccessKit) |

Préfixes réservés aux phases suivantes : `pages.*`, `edit.*`, `security.*`, `ocr.*`, `convert.*`, `cli.*`.

## Vérifications automatiques

- `crates/sunipdf-i18n` : parité des jeux de clés, aucune valeur vide, mêmes paramètres `{…}` dans les deux
  langues, clé inconnue renvoyée telle quelle (jamais de panique).
- `apps/sunipdf-desktop` : chaque clé littérale utilisée dans `app.rs`/`main.rs`/`shell.rs`/`workspace.rs` existe dans les deux
  catalogues ; chaque variante d'`EngineError` a une clé.
- `scripts/check-i18n.ps1` : même contrôle de parité hors Cargo (CI).

## Ajouter une clé

1. Ajouter `"prefixe.nom": "…"` dans `fr-FR.json` **et** `en-US.json`.
2. Utiliser `tr(lang, "prefixe.nom")` dans le code.
3. `cargo test -p sunipdf-i18n -p sunipdf-desktop`.
