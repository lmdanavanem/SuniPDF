# Themes and appearance

Open **Menu → Settings → Theme**, select the appearance button in the top bar,
or press **Ctrl+K** and search for **Theme settings**. No document needs to be open.

## Interface style

- **Classic** keeps the familiar SuniPDF appearance.
- **Liquid Glass** uses neutral surfaces, compact controls and subtle highlights
  on floating panels. Docked bars form a continuous workspace. The material is
  drawn inside the application; it does not blur the desktop behind the window.

The style applies to the workspace, tool panels, menus, dialogs and tables. PDF
page colors and saved document contents are unchanged.

## Color mode

Choose **Light**, **Dark** or **System** independently of the interface style.
System follows the appearance reported by the operating system while the app is
running. It falls back to Light when the platform provides no appearance preference.

Existing installations retain their previous light or dark choice in Classic.
Selecting a new appearance applies it immediately and saves it for the next launch.
If the preferences cannot be saved, the previous appearance remains active and
the panel shows an error.

## Reduce transparency

For Liquid Glass, enable **Reduce transparency** to use opaque surfaces without
the reflected highlights. The preference is retained when switching styles.

The Theme panel can be used with the keyboard. Its contents scroll in shorter
windows; **Escape** closes it without changing the document. You can switch back
to Classic at any time.
