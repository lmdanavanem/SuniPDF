# SuniPDF 0.41.0 — manual plan counts and annotation registers

Source slice; release qualification is pending. The current stable release remains [0.40.0](https://github.com/lmdanavanem/SuniPDF/releases/tag/v0.40.0) until qualification and publication complete.

- Count items by clicking on plans; persistent markers, groups, regrouping, movement/deletion and Undo/Redo.
- All-page annotation register with search, filters, sorting, navigation, business statuses, disciplines and custom text fields.
- CSV/JSON snapshots with totals linked to real marker identities; safe spreadsheet cells, explicit unknowns and stale-edit guards.
- Test-only Pillow 13.0.0, pinned Windows wheel hashes and previous 0.40.0 packages in upgrade qualification.

[Usage, CLI and limits](MARKUP_REGISTER.md) · [AEC backlog](AEC_BACKLOG.md). Count markers are manual; custom fields are text only. Cloud and collaboration remain deferred. The [1.0 qualification gates](RELEASE_1.0_CRITERIA.md) remain open.
